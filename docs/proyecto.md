# TFG Tattoo

## Objetivo
Desarrollar una aplicación web que permita gestionar citas y mostrar el portfolio de un tatuador, facilitando la organización del trabajo y la comunicación con los clientes.

## Funcionalidades principales
- Registro e inicio de sesión de usuarios
- Visualización de tatuajes (portfolio)
- Solicitud de citas
- Gestión de citas por parte del administrador
- Gestión de tatuajes (CRUD)
- Gestión de disponibilidad

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- phpMyAdmin
